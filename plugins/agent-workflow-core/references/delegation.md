# Delegation

Use the host's collaboration tools to delegate independent work when it could save time or improve
quality. Within the authorized task, do this proactively without asking for each assignment. Honor
host restrictions; work directly when delegation is unavailable or the work is too small or coupled
to benefit.

This applies to coordinating agents and subagents alike, within the host's available capacity and
the task's budget. Each agent remains responsible for work it delegates; passing it onward is not
completion.

Give each delegate a bounded outcome, relevant context and settled decisions, permitted changes,
and the evidence needed to assess completion. Assign distinct ownership for concurrent edits;
sequence overlapping changes or isolate them with a clear integration plan. Keep useful independent
work moving while delegates run instead of duplicating their assignments.

Delegates inherit the task's scope and authorization boundaries. Planning work remains planning,
unresolved user decisions return to the coordinating agent, and delegation grants no additional
authority for external actions.

The task's coordinating agent owns user questions, final synthesis, shared lifecycle records, and
Git commits. Inspect delegated findings or changes and validate the combined result as the task
requires. Resolve failures or unfinished assignments by taking over or reassigning them; finish or
stop outstanding delegated work before closing the task or advancing beyond its current batch.
